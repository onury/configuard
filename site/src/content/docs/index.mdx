```ts
const cfg = new Configuard(rows, { accessor: AccessorType.SYSTEM });
cfg.get<number>('device.port'); // 8080 — typed & nested, built from flat config rows
cfg.has('device.ui.accent');    // true
```

<div class="feature-grid">
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-list-tree feature-icon fi-orange"></i>
      <h3>Flat → Nested &amp; Typed</h3>
    </div>
    <p>Turn a tall <code>key / value</code> config table into a nested object, each value cast to its declared type.</p>
  </div>
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-variable feature-icon fi-green"></i>
      <h3>Templating</h3>
    </div>
    <p><code>${'{...}'}</code> references resolve recursively; circular and missing references are caught, not ignored.</p>
  </div>
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-shield-lock feature-icon fi-purple"></i>
      <h3>ABAC Filtering</h3>
    </div>
    <p>Each row declares an accessor; clients see only what their accessor and bitwise app level allow.</p>
  </div>
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-snowflake feature-icon fi-blue"></i>
      <h3>Immutable &amp; Fail-Loud</h3>
    </div>
    <p>The built object is deep-frozen by default, and a corrupt row throws at construction — never a silent partial build.</p>
  </div>
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-arrows-exchange feature-icon fi-red"></i>
      <h3>Admin Round-Trip</h3>
    </div>
    <p><code>parseFlat()</code> renders rows as editable fields; <code>serializeFlat()</code> validates edits back into a DB-ready diff.</p>
  </div>
  <div class="feature">
    <div class="feature-head">
      <i class="ti ti-key feature-icon fi-yellow"></i>
      <h3>Encryption-Aware</h3>
    </div>
    <p>Bring your own crypto: a <code>decrypt</code>/<code>encrypt</code> hook handles <code>encrypt: true</code> values at rest.</p>
  </div>
</div>
